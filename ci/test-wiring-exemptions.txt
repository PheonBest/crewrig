# test-wiring-exemptions.txt — allowlist of legacy-format test scripts under
# scripts/tests/ (named test-<name>, extension included) that are deliberately
# NOT executed by any CI workflow (spec 0076). The migration to TypeScript
# retired every such script, so no entry remains; the file stays because the
# guard reads it.
#
# Format, one entry per line:
#
#   <test-script-name><TAB><human-readable reason>
#
# Blank lines and lines starting with '#' are ignored. Enforced by
# scripts/check-test-wiring.ts:
#   - every entry MUST carry a reason (an empty reason fails the check, R3);
#   - every entry MUST name a test that still exists under scripts/tests/
#     (a stale entry fails the check, R5).
#
# Hygiene: when a quarantined (bug-exempted) test is later fixed and wired into
# a workflow, DELETE its line here. A test that is both wired and exempted is a
# redundant exemption — the guard tolerates it, but it is dead weight and hides
# the fact that the underlying bug is resolved.
